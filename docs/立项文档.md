## 一句话定位

**FlowPilot**：把自然语言描述的重复网页工作（采集、填表、比价、汇总）变成**可规划、可执行、可回放**的浏览器自动化流程——NVIDIA Nemotron 负责理解与规划，Tavily 提供实时网页情报与内容抽取，全程运行在 Nebius Token Factory 上。

Devpost 一句话（英文）：
> FlowPilot turns plain-English instructions into reliable, replayable browser workflows: NVIDIA Nemotron plans the steps, Tavily searches and extracts the live web, and everything runs on Nebius Token Factory.

## 用户与场景

目标用户：跨境电商运营、销售/BD、独立开发者、研究员——每天在网页上做重复信息工作的人。

MVP 聚焦 2 个演示场景（都要真实可跑）：
1. **批量采集**："把这 20 家公司官网的联系方式/定价要点整理成表格" —— Tavily Search 找官网 → Tavily Extract 抽内容 → Nemotron 归一化成表
2. **流程自动化**："去 X 网站搜索 Y 关键词，把前 10 条结果的标题/链接/价格填进表格" —— Playwright 执行交互步骤

（备选场景 3：定时监控竞品定价变动——加分项，时间允许再做）

## 功能范围

**MVP 必做（M1，~10-01）**
- 自然语言 → 流程计划（受限 JSON DSL），计划可人工确认/微调后执行（human-in-the-loop）
- Tavily Search + Extract 集成
- Playwright 受限步骤执行器（navigate/click/type/extract/wait/screenshot）
- 执行实况事件流（SSE）+ 结构化结果表（CSV 导出）
- Web UI（React）：目标输入 + 步骤时间线 + 结果表

**应做（M2，~10-15）**
- 步骤失败重试 + 人工接管提示
- 执行回放（截图序列）
- 多轮修改："把第 2 步改成只抓价格" → 增量改计划
- Demo 部署公网可访问（决策点：Nebius AI Cloud VM 或平价 VPS）
- **Tavily 集成加深**（主办方动机分析结论）：用上 Crawl（整站抽取）/ Map（站点结构发现）端点，提交材料里写清"为什么是 Tavily 而不是裸爬虫"——Tavily 已并入 Nebius，该奖评审大概率是 Tavily 自己人，看的是深度

**明确不做（防 scope 爆炸）**
- 多用户/账号系统/计费
- 反爬对抗（验证码破解等）——遇到就优雅失败 + 说明
- 移动端、桌面客户端、非浏览器类 RPA（Excel、桌面软件）

## 技术架构

```
React (Vite, :5173) ── FastAPI (:8000) ──┬─ Planner: Nemotron Super（Token Factory，OpenAI 兼容 API，JSON mode）
                                          ├─ TavilyTool:  /search + /extract
                                          └─ BrowserTool: Playwright(headless Chromium) 执行受限 DSL
                    执行实况: SSE 事件流 → 前端步骤时间线
```

**关键设计决策**
1. **受限 DSL 而非生成裸代码**：Nemotron 输出 JSON 步骤计划（固定 action 枚举），由确定性执行器运行——可控、可回放、可人工审核，可靠性比"让 LLM 写 Playwright 脚本再执行"高一个量级，且天然安全（白名单动作）。
2. **Tavily 优先，浏览器兜底**：静态内容用 Tavily Extract 直接拿，只有必须登录/交互的步骤才开浏览器——更快、更稳，也是 Tavily 使用深度的体现（Tavily 奖叙事）。
3. **单模型策略**：Nemotron Super 一个模型承担规划+改写+归一化（降低集成面），Ultra 留作困难规划后备。（2026-09-12 目录核查：平台已切至 Nemotron-3 代，默认 ID `nvidia/nemotron-3-super-120b-a12b`，smoke 脚本自动校正。）
